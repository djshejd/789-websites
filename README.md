# 789 網站

GitHub Pages 靜態網站。

- `index.html`：入口首頁
- `breakfast.html`：早餐英文與多益練習
- `taitung.html`：慢遊台東
- [`car-care/`](car-care/)：里程誌汽車保養紀錄 App；使用方式見 [說明](car-care/README.md)。

在 Settings → Pages 選擇 Deploy from a branch，分支 main，資料夾 / (root)，儲存即可。

所有網頁與圖片均使用相對路徑，可部署於 GitHub Pages 專案子路徑。地圖、路線查詢與 Google Fonts 需要網路；發音依裝置瀏覽器提供的語音。

Leaflet 授權見 taitung-leaflet-LICENSE.txt。
