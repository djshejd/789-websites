# 里程誌 DriveLog

適合手機使用的汽車保養與維修紀錄網頁 App。純 HTML、CSS、JavaScript，無須建置或 API 金鑰。

## 功能

- 多車輛管理與里程更新。
- 保養、維修項目、日期、里程、費用、店家與備註。
- 自訂日期或里程提醒；僅在 App 內顯示，不會傳送背景通知。
- 年度費用統計、搜尋與分類篩選。
- 完整 JSON 備份匯出、合併匯入及費用 CSV。

## 使用與資料保存

開啟網站後新增第一台車輛即可使用。紀錄保存在目前瀏覽器的 localStorage，不會上傳至 GitHub，也不會自動跨裝置同步。

更換網址、手機、瀏覽器或清除網站資料前，請先匯出完整 JSON 備份，再到新環境匯入。GitHub 上的版本沒有 ChatGPT 登入限制；個人紀錄仍只保存在各自的瀏覽器。

## 本機預覽

需要 Node.js。切換到此資料夾後執行：

~~~sh
node serve.mjs
~~~

使用瀏覽器開啟 http://127.0.0.1:4174 。

## 部署

可直接放在 GitHub Pages 或其他靜態網站主機的目錄，並使用 index.html 作為入口。所有資源均使用相對路徑，支援專案子目錄。Google Fonts 需要網路，無網路時會改用系統字型。

本程式不包含私人紀錄、測試資料、登入憑證或原 Sites 主機設定。
