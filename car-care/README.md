# 里程誌 DriveLog

適合手機使用的汽車保養與維修紀錄網頁 App。純 HTML、CSS、JavaScript，無須建置或 API 金鑰。

## 功能

- 多車輛管理、里程更新與選填車輛照片。
- 保養、維修項目、日期、里程、費用、店家與備註。
- 自訂日期或里程提醒；僅在 App 內顯示，不會傳送背景通知。
- 年度費用統計、搜尋與分類篩選。
- 「車輛比較」可並排比較 2 至 10 輛車，查看各車的年式、目前里程、保養筆數、最近紀錄及各類費用，支援全部年度與單年篩選。
- 直接匯入 Excel（.xlsx）、CSV 表單或保養單照片，預覽分類結果、重複紀錄與錯誤列。
- 完整 JSON 備份匯出、合併匯入及費用 CSV。

## 匯入保養表單

新增車輛後，進入「保養紀錄 → 匯入保養表單」。可下載 CSV 欄位範本，也可使用既有 Excel 檔或此 App 匯出的費用 CSV。每列填一筆紀錄，必要欄位為日期、里程（公里）與項目。費用可留白，匯入時會記為 0 元。

明確填寫的分類會優先採用。分類空白或無法辨識時，依保養項目分類為定期保養、維修、耗材更換，或檢驗／其他。可先確認預覽，匯入後也能編輯個別紀錄。表單如果有車輛名稱或車牌，須符合車庫中的既有車輛；兩欄皆留空時，使用目前選擇的車輛。重複或資料有誤的列會略過，原有紀錄會保留。

Excel 表單會檢查各個工作表，支援 Excel 日期欄與西元或民國日期文字。CSV 使用逗號分隔，支援 UTF-8 或 Big5。單一表單上限為 5 MB。檔案在瀏覽器內解析，Excel 讀取器隨 App 提供，授權見 `vendor/LICENSE.txt`。

### 保養單照片

在「匯入保養表單」選擇一張 12 MB 以下的 JPG、PNG 或 WebP。系統會辨識繁體中文與英文，嘗試帶入保養日期、里程、項目、總費用、車牌與店家。每張照片建立一筆紀錄。核對欄位後按「預覽分類」，確認結果再匯入。原始照片與完整辨識文字只在匯入時保留，核對後確認的欄位才會寫入本機紀錄。

OCR 在瀏覽器中執行，辨識品質取決於影像清晰度與版面。引擎與語言檔在選取照片時從本站載入。使用 Tesseract.js 6.0.1、Tesseract.js Core 6.0.0 與 chi_tra／eng 4.0.0_best_int 模型，授權檔在 `vendor/ocr/`。

## 使用與資料保存

開啟網站後新增第一台車輛即可使用。可點選車輛總覽右側的插圖或照片，直接新增或更換目前車輛的照片。新增或編輯車輛時也可選擇 JPG、PNG 或 WebP 照片（12 MB 以下），預覽後儲存。照片會在瀏覽器縮小，顯示於車輛總覽及車庫，並包含在完整 JSON 備份。紀錄保存在目前瀏覽器的 localStorage，不會上傳至 GitHub，也不會自動跨裝置同步。

更換網址、手機、瀏覽器或清除網站資料前，請先匯出完整 JSON 備份，再到新環境匯入。GitHub 上的版本沒有 ChatGPT 登入限制；個人紀錄仍只保存在各自的瀏覽器。

## 本機預覽

需要 Node.js。切換到此資料夾後執行：

~~~sh
node serve.mjs
~~~

使用瀏覽器開啟 http://127.0.0.1:4174 。

## 部署

可直接放在 GitHub Pages 或其他靜態網站主機的目錄，並使用 index.html 作為入口。所有資源均使用相對路徑，支援專案子目錄。Google Fonts 需要網路，無網路時會改用系統字型。

本程式不包含私人紀錄、測試資料、登入憑證或原 Sites 主機設定。
